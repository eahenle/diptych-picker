# v1.0 feature matrix

This is the public v1.0 scope contract. Every shipped feature has a stable ID,
public documentation, a reproducible example case, and automated evidence.
`npm run docs:check` enforces one matching scenario for every row.

Experimental entries are runnable but are not required for the ordinary
offline or agent-backed experience.

## Scope rule

A feature can enter v1.0 only when its row has all four evidence columns. A
future feature starts in [Product notes](PRODUCT_NOTES.md) and does not become
public scope merely because a proposal document exists.
