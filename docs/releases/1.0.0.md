# Diptych Picker 1.0.0

Diptych Picker 1.0.0 is the first stable public release of the local-first
two-image preference game.

## Highlights

- Deterministic offline demo with five MIT-redistributable seed images.
- Agent-backed generation with one persistent mailbox monitor and up to three
  fresh native-image workers.
- Exact-winner preservation, tie and both-lose decisions, Elo pool, favorites,
  history, full-size inspection, and candidate-derived variations.
- Fine-grained preferences, private source-image analysis, adaptive freedom,
  revisions, presets, editable rules, and moderation recovery.
- Weighted prompt cards, approval-gated repair and blending, and card writing
  from generated favorites.
- Versioned saves, durable crash recovery, content-addressed assets, and an
  experimental acknowledged co-proc notification transport.
- Complete public guides, 32 feature scenarios, seven runnable API clients, and
  automated documentation-drift enforcement.

The complete scope contract is the
[v1.0 feature matrix](https://github.com/eahenle/diptych-picker/blob/v1.0.0/docs/FEATURE_MATRIX.md).

## Compatibility baseline

- Node.js 24 or newer.
- Local single-user deployment on `127.0.0.1`.
- Versioned game snapshot import/export.
- Durable file-backed agent mailbox.
- Five bundled curated PNGs under MIT.
- No web-app API key input or model subprocess.

Experimental co-proc channels remain optional. The durable mailbox and
persistent monitor are the supported fallback.

## Release verification

- `npm ci`
- `npm run docs:check` — 28 Markdown files and 32 feature scenarios
- `npm run check` — 470 unit/integration tests and 20 mailbox protocol tests
- `npm run build`
- `npm run test:e2e` — 23 Chromium scenarios
- `npm audit --omit=dev` — 0 vulnerabilities
- All seven public API scripts against isolated deterministic demo state
- Clean source-archive installation and offline-demo smoke test
- Live agent-provider probe with
  `X-Diptych-Generation-Provider: agent`
- GitHub `validate` and `e2e` jobs

The release archive contains exactly the five manifest-listed seed PNGs and no
local data, environment overrides, worker handoffs, or generated artifacts.
