# Curated seed images

These five 1254×1254 PNGs make the deterministic offline demo immediately
playable. They are immutable game candidates rather than screenshots or
documentation:

| File                        | Depiction                                                                                            | Repository provenance                                                                                                       |
| --------------------------- | ---------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `coastal-observatory.png`   | A retrofuturist radio observatory on a stormy Pacific Northwest cliff at blue hour.                  | Entered the repository with the initial application build. The original generation session is not recorded.                 |
| `crystal-synthesizer.png`   | An aged analog synthesizer overtaken by clear and violet crystal growth.                             | Entered the repository with the initial application build. The original generation session is not recorded.                 |
| `mushroom-maestro.png`      | A commanding conductor directing luminous mushroom marionettes in a gothic theater.                  | Copied without re-encoding from a previously verified live-test generation; the original worker/session ID is not recorded. |
| `pool-sized-circuit.png`    | An overhead view of fabricators turning a drained public pool into a copper circuit board.           | Copied without re-encoding from a previously verified live-test generation; the original worker/session ID is not recorded. |
| `midnight-laundry-tide.png` | A laundromat attendant folding luminous fabric while immense translucent sea creatures pass outside. | Copied without re-encoding from a previously verified live-test generation; the original worker/session ID is not recorded. |

The files contain no embedded creator, copyright, prompt, software, or
generation-provider metadata. Their prompts and display metadata are preserved
in `manifest.json`.
